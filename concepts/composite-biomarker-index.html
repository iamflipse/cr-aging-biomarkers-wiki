The Composite Biomarker Index

The study's core instrument: a composite index of 6 blood-based biomarkers selected via the TAME (Targeting Aging with Metformin) Biomarkers Workgroup framework — markers with the strongest evidence for capturing core aging hallmarks (inflammation, insulin/IGF-1 signaling, cellular stress) that remain feasible in large geroscience trials.

BiomarkerDomain
CRPsystemic inflammation
IL-6inflammation
TNF-R1inflammation / innate immunity
Insulinmetabolic / insulin-IGF-1 axis
GDF-15cellular stress / senescence
Cystatin Crenal function

How the index is scored

Each biomarker's change (follow-up minus baseline) is assigned to a quintile, and the quintiles are summed — the "quintile sum score." Improvements in the index = a lower sum (markers moving in the favorable direction).

Why a composite

  • Single biomarkers like GDF-15 and cystatin C showed considerable between-study heterogeneity; the composite index gave a consistent signal across all 7 pooled trials.
  • Composite indices reduce the variability inherent to single-biomarker approaches and reflect real-time physiological response rather than a fixed "biological age" — unlike epigenetic clocks or telomere length, which correlate only weakly-to-moderately with each other (each reflects a different aspect of aging).

Prior validation

The same panel was previously validated in a randomized CR + exercise trial in older adults with HFpEF, where it demonstrated sensitivity to intervention-related change in a comparably aged, comorbid population (ref 14).
